DAQUI PARA O SEU SITE

Você escolhe.

do resto.

Uma skill é um pequeno manual que ensina seu assistente de programação a fazer uma tarefa. Esta já vem com a turma inteira na mala.

Abrir o guia completo ↗
01

Ensine seu agente

Abra o terminal do seu projeto e instale a skill. Escolha o assistente que você usa.

npx skills add asimov-academy/mascote-cursor --skill mascote-cursor
02

Peça do seu jeito

No chat do assistente, diga onde ele deve aparecer.

Use a skill mascote-cursor para colocar a Capi ao lado do título do meu site.

03

Pronto. Agora é dar um oi.

O agente integra os arquivos e confere o resultado. Sem chave de API para usar os mascotes prontos.
