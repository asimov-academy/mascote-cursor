DAQUI PARA O SEU PROJETO

Primeiro a skill. Depois o pedido.

A skill é um pacote com os mascotes, o código e as instruções para seu assistente. Escolher um personagem nesta página é só uma prévia — ainda não instala nada.

  1. 01

    Encontre a skill no GitHub.

    O botão no topo abre o repositório oficial, com os mascotes, a skill e o guia completo. O próximo passo baixa e instala esse pacote para você. Prefere o download manual? Use Code → Download ZIP e siga o README da pasta extraída.

  2. 02

    Instale no assistente do seu projeto.

    Abra seu projeto no editor e execute este comando no terminal. Ele baixa a skill diretamente do GitHub e pergunta em qual assistente instalar; por esse caminho, você não precisa baixar o ZIP. 

    npx skills add asimov-academy/mascote-cursor --skill mascote-cursor

    Precisa de Node.js 22 ou superior. Se já baixou o ZIP, o README também explica a instalação local. Abra uma nova conversa caso o assistente não reconheça a skill.

  3. 03

    Com a skill instalada, peça o mascote.

    Agora sim, envie este pedido no chat do assistente que está com seu projeto aberto:

    O pedido acompanha sua escolha na coleção. O agente integra os arquivos; depois, confira o resultado no navegador.

Quer criar um personagem próprio? O mesmo pacote inclui o processo de criação e o revisor de poses. Comece pela instalação da skill.
