Comece com a Capi de exemplo ou abra uma folha em grade 3 × 4: PNG, JPG, WebP ou SVG.

Precisa preparar?

Use quando a folha veio com fundo colorido ou em JPG/WebP. O revisor remove o fundo, alinha os ombros e gera um PNG transparente de 1536 × 2048. SVG desenhado no padrão não precisa deste passo; use só se quiser o mesmo mascote em PNG.

3. Leve para o seu site

O botão copia o HTML. Salve sua imagem (PNG preparado ou SVG) no projeto e carregue o módulo mascote.js para ativá-lo.
